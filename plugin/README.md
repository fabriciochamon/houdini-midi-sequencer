How to install the plugin:

1. Copy "plugin" folder to your machine
2. Edit `MidiSequencer.json` file and point "MIDI_SEQUENCER" var to your machine path
3. Save the .json file inside your Houdini packages folder, example:
	- C:\Users\<your_name>\Documents\houdini22.0\packages\MidiSequencer.json
4. Restart Houdini


The HDAs will be available in a SOP context, under "Midi" category.
